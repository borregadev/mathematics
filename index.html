Session 1 Part B: Our View of Numbers (Decimal System)

Positional notation, MSD/LSD, fractional values, and negative signed values.

MSD vs LSD

Most Significant Digit (MSD): Leftmost non-zero digit with the highest positional weight.
Least Significant Digit (LSD): Rightmost digit with the smallest weight.

413219₁₀ = (4×10⁵) + (1×10⁴) + (3×10³) + (2×10²) + (1×10¹) + (9×10⁰)

Decimal Point & Negatives

Digits after the decimal point represent fractional powers of 10 (1/10, 1/100, etc.). Negative signs (-) indicate debt or offset from zero.

5421.3456 = 5×10³ + 4×10² + 2×10¹ + 1×10⁰ + 3/10 + 4/100 + 5/1000 + 6/10000

Session 1 Part D: Exponents & Indices

Base index form, positive indices for Base 10, and zero power property.

Base Index Form

Written as baseindex. Represents multiplying the base by itself index many times.

2⁸ = 256

Zero Index Rule

Any non-zero number raised to the power of 0 equals 1.

5⁰ = 1, 100000⁰ = 1

Base 10 Powers

10ⁿ is simply 1 followed by n zeros.

10⁵ = 100,000

Session 1 Part E: Computer's View of Numbers (Binary Base 2)

Binary representation, MSB/LSB, Binary to Decimal conversion, and Division-by-2 method.

Binary → Decimal Conversion

Multiply each bit by its positional power of 2 (2⁰, 2¹, 2², ...):

10011₂ = (1×2⁴) + (0×2³) + (0×2²) + (1×2¹) + (1×2⁰)
       = 16 + 0 + 0 + 2 + 1 = 19₁₀

Decimal → Binary (Division Method)

Repeatedly divide by 2; extract remainders bottom-up (MSB to LSB):

13 / 2 = 6 r 1  (LSB)
6 / 2 = 3 r 0
3 / 2 = 1 r 1
1 / 2 = 0 r 1  (MSB) → Result: 1101₂

Session 2 Part B: Boolean Logic & Propositions

Definition of atomic propositions, boolean variables, and truth values (T/F).

Valid Propositions

Declarative statements that have a definitive truth value (either True or False):

  • • "Paris is the capital of France" (True)
  • • "2 + 2 = 5" (False)
  • • p = "I am awake" (Boolean Variable)

Non-Propositions

Sentences that do not possess a true/false truth value:

  • • Questions: "Is it raining?"
  • • Commands: "Go away!", "Turn off heating"
  • • Paradoxes: "I am lying to you now"

Session 3 Part B: Step-by-Step Complex Proposition Evaluation

Solving complex expressions by systematic step replacement.

Evaluation Walkthrough: ~((T ∧ F) → ~T) ∨ F 

~((T ∧ F) → ~T) ∨ F
  1. Evaluate (T ∧ F)  ⇒ F → ~ (F → ~T) ∨ F
  2. Evaluate ~T        ⇒ F → ~ (F → F) ∨ F
  3. Evaluate (F → F)   ⇒ T → ~ T ∨ F
  4. Evaluate ~T        ⇒ F → F ∨ F
  5. Evaluate F ∨ F     ⇒ F

Final Result = F

Session 4 Part A: Set Fundamentals & Representation Forms

Enumerated form, Predicate form, Special Sets (ℕ, ℤ, ℚ, ℝ, ∅, U), and membership (∈, ∉).

Representation Forms

  • • Enumerate: Explicit list inside curly braces: {2, 4, 6, 8}
  • • Predicate: Property definition: {x : x is an even number}
  • • Unordered & Distinct: {1, 2, 3} = {3, 1, 2} and {1, 1, 2} = {1, 2}

Special Sets Notation

ℕ = {1, 2, 3, ...}
ℤ = {..., -1, 0, 1, ...}
ℚ = Rational numbers
ℝ = Real numbers
∅ = Empty set {}
U = Universal set

Session 4 Part B: Predicates & Quantifiers (∀, ∃)

Universal Quantifier (∀) and Existential Quantifier (∃).

Universal Quantifier (∀)

"For every / For all". True ONLY if predicate holds for every single element in set A.

∀x ∈ {2, 4, 6}, x is even  ⇒ TRUE

Existential Quantifier (∃)

"There exists". True if predicate holds for AT LEAST ONE element in set A.

∃x ∈ {2, 4, 7}, x is odd  ⇒ TRUE (x=7)

Session 4 Part C: Subsets, Proper Subsets & Power Sets

Subset rules (⊆), proper subsets (⊂), set cardinality |A|, and power sets 𝒫(A).

Subsets vs Proper Subsets

  • • Subset (A ⊆ B): Every element in A is also in B. Note: A ⊆ A is always true.
  • • Proper Subset (A ⊂ B): A ⊆ B AND A ≠ B. (A set is never a proper subset of itself).
  • • Empty Set Rule: ∅ ⊆ A for every set A. ∅ ⊂ A for every set except ∅.

Power Sets 𝒫(A) & Cardinality

The set of ALL subsets of A. Cardinality formula: |𝒫(A)| = 2|A|

For A = {1, 2}:
𝒫(A) = { ∅, {1}, {2}, {1,2} }
|𝒫(A)| = 2² = 4 subsets
