Session 1 Part B: Numbers, Sets & Expressions

Classification of real number systems, mathematical expressions, variables, and constants.

Number Sets Taxonomy

Natural Numbers (ℕ): {1, 2, 3, 4, ...}
Integers (ℤ): {..., -2, -1, 0, 1, 2, ...}
Rational Numbers (ℚ): Numbers p/q (q ≠ 0).
Real Numbers (ℝ): Rational and irrational values (π, √2).

Expressions vs Equations

An Expression is a phrase combining variables, numbers, and operators without an equals sign (e.g. 3x + 5).

An Equation states that two expressions are equal using an equals sign (e.g. 3x + 5 = 20).

Session 2 Part B: Propositions & Boolean Variables

Propositions, truth values (T/F), and variable declarations (p, q, r, s).

Proposition Definition: A statement that is strictly True (T) or False (F).

Questions ("Is it raining?") and commands ("Close the door!") are NOT propositions because they lack truth values.

Session 2 Part C: Compound Propositions

Combining atomic propositions using connective logic operators.

Atomic Proposition

A single variable representing one statement (e.g. p = 'I am awake').

Compound Proposition

Formed by connecting atomic propositions (e.g. p ∧ q = "I am awake AND I am studying").

Session 3 Part A: Evaluating Compound Propositions & Place Markers

Understanding truth values as statements and using truth table columns as positional place markers.

'True' and 'False' as Statements

'true' and 'false' are valid statements with constant truth values:

• 'true' = T
• 'false' = F

Because T and F are propositions, they combine directly with operators (e.g. T ∧ F or F ➔ T).

Place Marker Principle

When evaluating expressions using truth tables, variables p and q act as positional markers:

  • • p = Place marker for expression on the LEFT
  • • q = Place marker for expression on the RIGHT

Worked Walkthrough: q ➔ p when p = T and q = F

CRITICAL RULE: Right-to-Left Precedence for Equal Operators

When operators have the same precedence level (or the exact same operator repeated) without parentheses (e.g. T ∧ F ∧ T or F ↔ T), evaluation proceeds FROM RIGHT TO LEFT.

Stepwise Reduction Trace: ~((T ∧ F) ➔ ~T) ∨ F

Step 1: Inner brackets (T ∧ F) ➔ F | Expr: ~(F ➔ ~T) ∨ F
Step 2: Negation inside brackets ~T ➔ F | Expr: ~(F ➔ F) ∨ F
Step 3: Conditional inside brackets (F ➔ F) ➔ T | Expr: ~T ∨ F
Step 4: Outer negation ~T ➔ F | Expr: F ∨ F
Final Value: F ∨ F = F
